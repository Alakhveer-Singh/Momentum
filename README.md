# Quibus LMS — Lead Management & CRM

Professional lead management system: pipeline kanban, lead scoring, activity tracking, tasks, email templates, reports, role-based access, and real-time notifications.

## Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React 19 + Vite + Tailwind CSS 4 + React Router 7 |
| Backend | PHP 8.2+ / Laravel 13 |
| Database | MySQL / MariaDB |
| Auth | JWT (`tymon/jwt-auth`) |
| Real-time | Laravel Reverb (Pusher protocol) + Laravel Echo |
| PDF export | `barryvdh/laravel-dompdf` |

## Features

- **Lead intake**: public web-form endpoint (rate-limited), manual entry, bulk CSV import
- **Pipeline kanban**: drag-and-drop across New → Contacted → Qualified → Negotiating → Won/Lost
- **Contact profiles**: full details, custom fields (JSON), notes, deal value
- **Activity tracking**: calls, emails, meetings, notes + automatic system/stage-change logs
- **Lead scoring (0–100)**: source quality + stage progression + engagement + profile completeness, recalculated automatically
- **Tasks**: priorities, due dates, assignment, overdue tracking, broadcast notification on assignment
- **Email templates**: placeholder rendering (`{{first_name}}` etc.), single & bulk send, logged as activities
- **Reports**: dashboard KPIs, pipeline by stage, lead source ROI, team performance, 6-month trend
- **Roles**: admin (everything), manager (all leads + reports), rep (own leads/tasks only)
- **Real-time**: lead updates + notifications over WebSockets, browser Notification API
- **Exports**: leads CSV, pipeline PDF
- **Responsive**: mobile sidebar, adaptive tables/cards

## Local Setup

### Prerequisites
PHP ≥ 8.2, Composer, Node ≥ 20, MySQL ≥ 8 running locally.

### 1. Database
```sql
CREATE DATABASE quibus_lms CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### 2. Backend
```bash
cd backend
composer install
cp .env.example .env          # then set the values below
php artisan key:generate
php artisan jwt:secret
php artisan migrate --seed    # creates schema + demo data
```

`.env` essentials:
```
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=quibus_lms
DB_USERNAME=root
DB_PASSWORD=
QUEUE_CONNECTION=sync
BROADCAST_CONNECTION=reverb
MAIL_MAILER=log               # swap for SMTP creds in production
```
(Reverb keys are generated by `php artisan reverb:install`.)

### 3. Run (three processes)
```bash
cd backend && php artisan serve              # API on :8000
cd backend && php artisan reverb:start      # WebSockets on :8080
cd frontend && npm install && npm run dev   # UI on :5173 (proxies /api → :8000)
```

Open http://localhost:5173

## Production Notes
- Set `APP_ENV=production`, `APP_DEBUG=false`, regenerate `APP_KEY`/`JWT_SECRET`.
- Build frontend with `npm run build` and serve `frontend/dist` behind nginx; proxy `/api` and `/app` (Reverb) to PHP-FPM/Reverb.
- Switch `QUEUE_CONNECTION` to `database`/`redis` and run `php artisan queue:work`.
- Configure real SMTP in `MAIL_*` for actual email delivery (local dev logs emails to `storage/logs/laravel.log`).
- Restrict CORS origins in `config/cors.php`.

See [API.md](API.md) for full endpoint documentation.
